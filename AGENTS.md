# AGENTS.md

Static HTML/CSS/JS course-practice site (Chinese content). Flat repo: **no package.json, no build, no lint, no tests.** Pages must work opened directly via `file://` — no `fetch`, no ES modules; third-party libraries are downloaded locally into `cdn/` and referenced by relative path.

## Hard workflow rules (from `zhouli_prompt.md`, the user's instruction log)

1. **Log the prompt before acting.** Before doing anything, *append* (never overwrite) an entry to `zhouli_prompt.md` with the same shape as existing ones: 时间 (Asia/Shanghai date), 使用的模型, 提示词内容 (verbatim prompt).
2. **Naming prefix.** Every CSS class, id, JS variable, and CSS custom property you create must start with `zhouli_` (e.g. `.zhouli_hero`, `--zhouli_ink`). Apply to new code; do not rename older pages that predate the rule.
3. **New pages link home.** Every new `.html` file must contain a hyperlink to `index.html` — existing pattern: `<a class="zhouli_back" href="index.html">返回首页</a>`.

## Layout

- `index.html` — homepage/course hub; all styles inline, course pages reachable via `.course-card` links. Not every page is listed there (e.g. `iconfont-*.html`, `JS_obj_fun.html` aren't) — don't add nav entries unless asked.
- `cdn/` — vendored third-party assets: Font Awesome (`cdn/css/all.min.css` + `cdn/webfonts/`), Lucide (`cdn/lucide.min.js`). Download new libraries here; treat the directory as read-only.
- `font/` — generated by iconfont.cn (project id 5238920): `iconfont.css/js/ttf/woff…` plus the generator's `demo_index.html`. Regenerate from the site; don't hand-edit.
- `img/` — page images (plus two stray layout-exercise files).
- `data.js` — plain `<script>` loaded before the inline script of `starter-level0532zhouli.html`; exposes `window.STUDENTS` / `window.SUBJECTS`. Don't convert to modules.
- `frontend-design/SKILL.md` — design guidance the user explicitly invokes for UI/visual work; follow it for any design or redesign request.
- Per-page styles live in a `*.css` next to the page or inline in `<style>`; there is no shared stylesheet — keep it that way unless asked.
